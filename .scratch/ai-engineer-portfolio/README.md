# Wayfinder: NeoBank as an AI Engineer portfolio

**The tracker is GitHub Issues. This directory only holds the supporting artifacts.**

- **Map:** [#16 — Map: NeoBank as an AI Engineer portfolio](https://github.com/YuukiFST/neobank-support-chatbot/issues/16), labelled `wayfinder:map`. Read it first every session.
- **Tickets:** open child issues of #16. The frontier is the open, unassigned children with no open blocker — GitHub renders blocking natively, so the takeable ones are visible without opening the map.
- **Claiming:** assign the issue to yourself *before* doing any work, so a concurrent session skips it.
- **Resolving:** post the answer as a comment, close the issue, then append one line to the map's *Decisions so far*.

## What lives here

| Path | What it is |
|---|---|
| `job-postings.md` | The 8 target job descriptions, condensed. Source of the acceptance criteria. Re-read before scoping any ticket. |
| `research/` | Findings from AFK research tickets, linked from the issue that commissioned them. |
| `research/inherited/` | Artifacts salvaged from the retired research-paper map (removed 2026-08-14): a literature survey on LLM agent architectures and tool selection, and two code audits with `file:line` evidence. |

`map.md` is not kept here — a second copy would drift from the issue. The issue is canonical.
