## P0 — GenAI Specialist / LLMOps (senior, PT-BR)

Transversal role supporting an LLMOps platform.

Responsibilities: build end-to-end GenAI solutions from technical conception to production operation; lead or support creation of copilots, automations and assistants with quality, security and scalability; evolve the LLMOps platform focused on governance, traceability, observability, cost and security; define and spread CI/CD practices applied to GenAI, on-premise and cloud; investigate production failures and incidents with root-cause analysis; promote code review, solution standardisation and knowledge sharing.

Requirements: proven experience with generative AI, LLMs, embeddings and NLP techniques; mastery of Python and frameworks such as LangChain or Transformers; **advanced RAG architectures including re-ranking, dynamic chunking and context-sensitive retrieval**; solid Git and relational + non-relational databases; data science over unstructured data; hands-on LLMOps — pipelines, versioning, monitoring, evaluation and model cost control.

Differentiators: open-source models (Mistral, LLaMA, Mixtral, Phi); autonomous agents or flow orchestration with LangGraph; emerging protocols **MCP and A2A**.

Build AI applications with GPT-4, Claude, Gemini.

Requirements: own/academic/internship projects in Python or JavaScript/TypeScript; real interest in LLMs; some contact with LangGraph, LangChain, agents and RAG; consuming REST APIs and building simple back-end/front-end flows; technical reading in English.

## P2 — OpenAI, Enterprise Applied AI Engineer

Partner with enterprise customers to design, build and deploy AI systems with measurable business outcomes.

Scope: translate opportunities into technical architectures, implementation plans, **evaluation strategies** and measurable success criteria; hands-on code for prototypes, **evaluation harnesses**, reference implementations, integrations; sound technical decisions across models, agents, retrieval, tools, data, reliability, observability, latency, cost, safety, security and governance; diagnose complex failures — reproduce, test hypotheses, drive to resolution; move customers from prototype to reliable production.

Requirements: track record designing and delivering AI/ML systems, prototype to production; substantial personal contributions in code, architecture, evaluation, debugging or production engineering; highly proficient in Python, comfortable across an AI application stack, JS/TS valuable; **understand how to evaluate AI systems systematically using representative data, graders, production signals and human judgement**; enterprise production requirements — integrations, reliability, observability, security, privacy, data governance, performance, cost.

## P3 — Amazon, SDE Agentic AI (Brazil)

Build capabilities that let AI agents act reliably on real operator workflows. Customers are operators: planners, ops managers, analysts, support leads.

Responsibilities: **review agent runs in production, triage operator corrections, and decide which are bugs versus signal that the autonomy boundary needs to move**; pair with operators, translate implicit rules into mechanisms the agent can execute; **close the feedback gap so every operator correction becomes a test, an eval or a prompt update, not lost noise**; own the roadmap, demo weekly, argue design choices in writing; decide which workflows are agent-ready and which still need a human in the loop; **monitor trust score, accuracy, latency and cost per decision, and dig into regressions before they compound**; trade off latency, cost and accuracy by judgement, not recipe.

Requirements: professional software development experience; contributing to architecture and design (design patterns, reliability, scaling); at least one programming language. Preferred: full SDLC — coding standards, code reviews, source control, build, testing, operations.

> This posting is the single strongest influence on the repositioning. The autonomy boundary and the correction-to-eval loop come from here.

## P5 — Caixa Vida e Previdência, AI Engineer (PT-BR)

Design, build and operate AI solutions in production focused on LLMs, RAG, agents and integration with corporate systems, ensuring scalability, governance and security.

Requirements by area:

- Software engineering: Node.js, Python, REST APIs and microservices, distributed architecture, .NET/C#.

- Generative AI: consuming LLM APIs; prompt engineering in production; understanding limitations (hallucination, cost, latency); **response quality evaluation**.

- Agents: multi-step orchestration with tools; corporate API integration; automations and workflows.

Differentiators: multi-agent; **model evaluation frameworks**; fine-tuning and embedding tuning; multimodal; real production LLM projects.
