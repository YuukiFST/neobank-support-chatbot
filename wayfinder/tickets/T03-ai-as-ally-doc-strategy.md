# T03 — "AI-as-ally in development" documentation strategy

## Question

The job explicitly says they use AI for dev, tests, and code review. Decide how the repo *shows* the candidate does this too — a concrete, defensible artifact, not a vague claim.

Options to weigh: a `docs/ai-assisted-development.md` describing the workflow (which tasks were AI-driven, prompts used, how output was reviewed); AI-in-CI (an LLM code-review or test-gen step); commit/PR conventions noting AI-assisted changes. Decide scope so it reads as real practice, not buzzword.

Output: decision on which artifact(s) to produce and where. Feeds tooling (T04) and evaluation (T10).
